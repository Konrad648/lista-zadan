# Lista zadań (To-Do) – aplikacja konsolowa

Prosta aplikacja konsolowa w Pythonie do zarządzania listą zadań. Projekt realizowany w ramach przedmiotu **Zarządzanie projektem wdrożeniowym** z wykorzystaniem Git, GitHub i Trello.

## Funkcjonalności

- wyświetlanie listy zadań,
- dodawanie nowych zadań,
- usuwanie zadań,
- oznaczanie zadań jako zrobione.

## Technologie

- Python 3.10+
- Git i GitHub (fork, gałęzie, Pull Requesty)
- Trello (planowanie i śledzenie zadań)

## Uruchomienie

1. Zainstaluj Pythona 3.10 lub nowszego: https://www.python.org/downloads/
2. Sklonuj repozytorium:
   ```bash
   git clone https://github.com/NAZWA_UZYTKOWNIKA/lista-zadan.git
   cd lista-zadan
   ```
3. Uruchom aplikację:
   ```bash
   python main.py
   ```
